# O teu Retrato Emocional do Dinheiro — Finanças com Alma

Quiz interativo. 6 afirmações, escala de 1 a 5, devolve o arquétipo emocional dominante e o arquétipo sombra.

## Como correr localmente

Abre `index.html` diretamente no browser (duplo clique, ou arrasta para uma janela do Chrome/Edge/Safari).

## Antes de partilhar

- Substitui `[LINK_A_DEFINIR]` no botão final pelo link real da tua Sessão Estratégica de Clareza Financeira.
- Testa no telemóvel — arrasta o ficheiro para o teu email ou iCloud e abre lá.

## Próximo passo (fora desta pasta)

Publicar online, com domínio próprio para o link da bio, é um passo técnico à parte. Por agora, esta pasta é tudo o que precisas para testar e afinar.
